## Project Description
This project is a terminal-based Python application developed for the Principles of Structured Programming course. The system allows users to input student details and scores, process the data, and generate a formatted academic report including GPA calculation.

## Features
- Accepts user input (name, course, student ID)
- Validates student ID
- Accepts multiple subject scores
- Calculates GPA
- Displays formatted academic report
- Uses structured programming (functions, loops, conditions)

## Technologies Used
